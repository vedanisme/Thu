# Fintech MVP – Budget & Saving Assistant

## Description
This project is a fintech MVP developed for a Finance & Fintech competition.
It demonstrates how AI-assisted logic can help users manage income, expenses,
and improve saving behavior.

## Key Features
- Income and expense input
- Overspending detection
- Rule-based AI recommendations

## Tech Stack
- HTML
- CSS
- JavaScript
- Replit AI (AI-assisted development)

## Notes
This MVP focuses on core functionality and business logic rather than
full production deployment.
